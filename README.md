# Pet World – Mini App para World App

Um hub social e gamificado para donos de pets e amantes de animais, 100% integrado ao ecossistema Worldcoin/World Chain.

## Funcionalidades
- Feed social de pets (fotos, vídeos, histórias)
- Perfil de pet real e adoção de pet virtual
- Mini-games diários (7 jogos viciantes)
- Comunidade: comentários, likes, eventos
- Loja com pagamento cripto
- Integração MiniKit: World ID, Wallet, Pay, Sign

## Tecnologias
- Next.js + Tailwind CSS
- @worldcoin/minikit-js
- Zustand, react-konva

## Estrutura
- src/pages: páginas principais
- src/components: componentes reutilizáveis
- src/games: mini-games
- src/store: Zustand stores
- src/mock: dados mockados
